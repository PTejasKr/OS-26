### 📦 Key Highlights

- **3D Mechanical Hard Drive Platter**: Photorealistic WebGL actuator arm kinematics, spindle motor rotation (7200 RPM), interactive surface raycasting, and real-time seek latency telemetry.
- **LRU Memory & Disk Swap Workbench**: Real-time synchronized workbench connecting Primary Memory (RAM frames) with Secondary Storage (hard disk swap cylinders), displaying live page-ins, DRAM cache hits (0.001 ms), and LRU victim churn-outs.
- **Monospace ASCII Blueprints**: Full 80-column plaintext schematics for academic documentation, course submissions, and viva voce exams.
- **Physical Disc Gallery**: A24-inspired editorial design language with holographic compact discs and spatial sound effects.
